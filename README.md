## ✨ Features

| Feature | Description |
|---------|-------------|
| 👥 **Two Players** | Player X vs Player O on the same device |
| 🏆 **Scoreboard** | Track wins for X, O and Draws |
| 🎉 **Win Animation** | Winner cells glow with celebration effect |
| 🔄 **New Round** | Reset board without losing scores |
| ♻️ **Reset Scores** | Clear all scores and start fresh |
| 📱 **Responsive** | Works on mobile, tablet, and desktop |
| ⚡ **Fast** | No external libraries — pure vanilla JS |

---

## 🕹️ How to Play

1. Open `index.html` in any browser.
2. Click on any empty cell to place your mark (**X** goes first).
3. Alternate turns between **X** and **O**.
4. Get 3 in a row (horizontal, vertical, or diagonal) to win!
5. If all cells fill without a winner, it's a **Draw**.
6. Click **New Round** to play again, or **Reset Scores** to start from zero.


Or simply double-click **`index.html`** in the folder.
